# KiraAI 手机助手

让 KiraAI 操作你授权的安卓手机：点击、滑动、输入文字，需要时发进度或截图。

首次配置或从旧版迁移后，在管理页点击“保存并启动”；以后重启自动恢复。自定义密码支持 8–128 位，新手引导只在 App 首次启动时弹出。

当前版本 **1.0.1**。KiraAI 安装 **`phone_control-1.0.1.zip`**，也可在 GitHub 安装处填 **`fcll32/kiraai-phone-assistant`**。手机单独安装 APK。

适用于 KiraAI **3.0.1 及以上**，已适配 3.1.0。

手机界面用 uni-app x 构建：柔和灰蓝背景、雾白卡片，底部保留设备、连接、通话三个页签。菜单里的“关于”集中放 GitHub 链接、应用更新和动效开关、速度设置；发现新版时，菜单按钮和“关于”条目显示红点。首页连接卡可翻面查看服务器与准备情况，连接按钮始终可见。保存和连接成功后按钮会收成勾号，步骤卡片可展开或左右滑动。

## 安装后怎么用

1. 在 KiraAI 的插件管理里上传 ZIP，或从 GitHub 安装 `fcll32/kiraai-phone-assistant`，安装并启用「KiraAI 手机助手」。
2. 打开左侧的 **手机连接** 页面，填服务器公网 IP 和允许使用的聊天，点“保存并启动连接”。
3. 插件自动生成连接密码、服务器校验码，并启动手机连接服务。
4. 单独下载发行目录中的 APK，装到手机，把页面上的三项连接信息复制进去。
5. 开启手机 App 的无障碍服务，点击“开始连接”。

**手机和管理网页可以共用公网 5267。** 浏览器使用 `https://公网IP:5267`，手机填写 `公网IP:5267`。先在插件页启用共用入口，再将 Docker 映射改为 `5267:8443`；备用管理映射为 `127.0.0.1:15267:5267`。具体迁移步骤见新手说明，无需安装 Nginx。

第一次使用请看 **[新手使用说明](新手使用说明.md)**，里面把每一步写清楚了。

## 手机支持范围

- Android 8–10：控制手机、读取页面文字和按钮位置。
- Android 11 及以上：还可以按需截图，部分应用可能禁止截图。

不持续录屏。App 内通话仅在你授权麦克风并点击开始后启用。手机和服务器不必连接同一个 Wi-Fi。可以在 App 或通知里停止连接。

支持图片的多模态模型可以直接看截图，也可以一次看 2–4 张连续画面，观察视频页面的变化。当前聊天的图片识别建议选 `native`，省去额外的图片描述请求。受保护视频可能黑屏；Android 8–10 没有这项看图能力。

支持点击、四向滑动、返回、桌面和多任务操作。App 内通话接入 Kira 默认语音识别、聊天与语音合成模型，当前轮流说话，支持静音、打断和挂断。虚拟麦克风目前是 Android 13+ / Shizuku 短测试音实验，不代表 QQ／微信已经兼容。

## 更新

安装新版插件 ZIP，手机 APK 单独下载更新。插件提示已存在时，卸载旧插件并保留“插件配置”和“插件数据”，再安装。手机如提示版本过低或签名不一致，先保存连接信息，再卸载旧 App、安装并重新填写；卸载会清除手机里的设置。

旧版已经用 Nginx 连接成功时，可以继续使用旧配置；切换内置服务时要换一个空闲端口，重新复制页面上的连接信息。

单独的 APK 方便直接安装；源码 ZIP 留给需要修改代码的人，普通用户不用下载。
