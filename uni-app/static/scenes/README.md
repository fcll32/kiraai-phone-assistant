# 页面场景背景

六张竖版背景均通过内置 imagegen 生成，以用户提供的原图保持相同角色、白蓝衣装和蓝紫色调。完整提示词见 `prompts.json`。

- device.png：早晨展示手机、开心迎接。
- connection.png：专注对齐连接线，认真接线。
- voice.png：戴耳机、闭眼倾听，放松陪伴。
- guide.png：看书、托腮思考，带疑问的眼神。
- about.png：眨眼展示画笔与星星，轻快创作。
- menu.png：窗边微笑挥手，迎接打开菜单。

AppBackdrop 根据页面切换本地图，菜单另用自己的场景。图按宽度展示而不是按全屏高度放大；短屏向上移动更多。页面标题区固定为人物留白，卡片在其下方独立滚动，人物正脸不进入卡片滚动区。只加载当前图，不做逐帧背景滤镜或自动轮播。欢迎引导保留原始背景图。
