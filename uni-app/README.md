# 手机 App 使用说明

1.0.0（功能基线与 1.1.9 相同）使用 uni-app x，支持 Android 8 起。安装发行包中的 APK 即可。详细配对见根目录「新手使用说明.md」。

## 连接与通话

在 KiraAI 安装插件 ZIP，打开「手机连接」，填公网 IP 和允许使用的聊天。App 底部点「连接」，复制服务器地址、密码和校验码；地址只需 `公网IP:端口`。开启无障碍服务后回到「设备」，点开始连接。草稿会保留，连接时先检查并保存输入；必须在确认弹窗中同意才启动。未就绪时查看按钮下方的提示。

「通话」页由你主动授权麦克风并开始通话；授权成功后需再次点击。服务器需配置默认聊天、语音识别和合成模型。虚拟麦克风仍是独立兼容性实验，不代表 QQ／微信通话可用。

背景改为低饱和灰蓝，卡片使用雾白，按钮和选中状态延续蓝色。首页文字与手机图案左右排列，缩短标题并统一行距；翻面、叠卡、滑动、弹窗、完成反馈和调速仍保留。

## 界面操作

- 首页连接卡：点「翻看连接概览」查看服务器、设备和准备情况；翻面不会开始连接，下方按钮始终保留。
- 底部四项：设备、连接、通话、偏好。胶囊随选择拉伸、回弹；内容按方向轻推入。关于从侧边菜单进入。
- 连接步骤可点标签或左右滑卡，松手按惯性吸附。当前卡片按压微倾、回弹后展开详情。
- 详情页头图视差、大标题吸顶；中间状态松手后自动展开或收起。点关闭返回。
- 设备页的手机能力卡可翻面；背面稳定后显示帮助和连接入口。
- 偏好里的动画速度面板升起时，背景缩小并变暗；顶部可上下拖，向下超过三分之一或快速甩动关闭。滚轮与顶部拖动区域分开，取消不保存草稿。
- 输入框用浮动名称代替占位文字，填写后名称保留在上方。
- 防截屏开关在侧边菜单底部，原生确认成功后才显示绿色；失败保留原状态。
- 保存、连接成功才显示完成勾号。动画速度可调，也可关闭各类动效，不改变实际连接或 AI 速度。

Android 8–10 仅提供控件信息和操作，11+ 可按需截图；不持续录屏。

## 构建与验证

参见根目录 DEVELOPMENT.md、VALIDATION.md。Web 只是界面预览，不能连接手机或采集麦克风。浏览器 390×844 排版和脚本回归不能替代 Android 真机触摸、帧率、截图保护及通话测试。

本版把 versionCode 特意重置为 1，已安装 1.1.9（code 11）的手机不能直接覆盖降级：先保存连接信息，再卸载旧 App、安装本版并重新填写。以后必须从 1.0.0/code1 递增；历史 1.3.x 先尝试同签名覆盖安装，若系统拒绝，按同样方式处理。
