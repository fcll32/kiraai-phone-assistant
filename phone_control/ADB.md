# 可选 ADB 连接（进阶用法）

普通用户请使用插件自带的“手机连接”页面和 Android App，不需要看这份说明。ADB 是另一种连接方法，需要电脑或服务器上的 Android 调试工具。

当前插件为 **1.0.0**，适用于 KiraAI 3.0.1 及以上。安装 `phone_control-1.0.0.zip` 后，在插件配置把“连接方式”改为 `adb`。其他安装和升级步骤见 ZIP 内的《新手使用说明.md》。

## 手机接在运行 KiraAI 的电脑上

1. 在电脑安装 Android Platform Tools，确保其中的 `adb` 能运行。也可以在插件的“ADB 程序路径”填写它的完整路径。
2. 在手机开发者选项开启 USB 调试，连接数据线，解锁手机并确认调试授权。
3. 在电脑运行 `adb devices -l`。手机状态需要是 `device`；如果是 `unauthorized`，先在手机上确认授权。
4. 只连接一台手机时，可以不填“设备序列号（仅 ADB）”。连接多台时，将上一步对应手机的第一列复制进去。
5. 在“允许使用的聊天”中填入自己的聊天会话 ID，再试：“检查手机连接，然后打开设置。”

ADB 模式不需要启动本项目的手机 App，也不需要填写 App 的连接密码和服务器校验码。插件依赖由 ZIP 安装器处理；ADB 程序仍需自行安装。

## KiraAI 在云端，手机接在家中电脑上

这种方式需要家中电脑持续运行，并通过 SSH 把本地 ADB 服务连接到云端。普通用户建议直接使用手机 App 公网连接。

在家中电脑确认 `adb devices -l` 正常后，运行下面的命令，将 `USER@SERVER` 换成自己的服务器登录信息：

```sh
adb start-server
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -o ServerAliveCountMax=3 -R 127.0.0.1:15037:127.0.0.1:5037 USER@SERVER
```

保持连接运行。服务器需要允许 SSH 转发，并安装 ADB 客户端。然后在服务器检查：

```sh
adb -H 127.0.0.1 -P 15037 devices -l
```

插件配置中，“ADB 服务主机（仅 ADB）”填 `127.0.0.1`，“ADB 服务端口（仅 ADB）”填 `15037`，再按需填写设备序列号。不要把 ADB 端口开放到公网。

如果 KiraAI 在 Docker 内，ADB 客户端也必须在容器里可用。桥接网络中的 `127.0.0.1` 指容器自身，不能直接照抄宿主机地址；需要另外安排容器到该转发端口的连接。

## 中文输入与截图

普通 ADB 输入只支持可打印英文字符。中文输入需要自行安装、启用并切换到 ADB Keyboard，再将插件的“文字输入模式（仅 ADB）”改成 `adb_keyboard`。插件会检查输入法，不会替你切换。

ADB 模式可在旧 Android 上获取截图，但受保护页面仍可能无法截图。让 AI 看图时，仍需正确配置 KiraAI 的图片识别模型。手机 App 的 Android 8–10 模式依旧只提供控件信息。

AI 可以按需发送文字进度和截图，不生成语音。发生超时或断线时，操作可能已经执行，应先重新观察再决定是否重试。
