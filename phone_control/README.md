# KiraAI 手机助手 · KiraAI 插件

首次配置后，请在“手机连接”页点一次“保存并启动”；随后重启自动恢复，手动停止后保持停止。自定义密码可填 8–128 位英文字母、数字或符号，不含空格。

当前版本 **1.0.0**，适用于 KiraAI 3.0.1 及以上。

请让 AI “把当前手机截图发到这个聊天”，对应 `phone_screenshot(send_to_chat=true)`；已有截图也可用 `phone_report` 发送。

图片单独传入上下文，不会随文字一起截断。通话只开放手机工具，不自动引入跨聊天的长期记忆。

## 安装 ZIP 后就能准备连接

1. 在插件管理上传 `phone_control-1.0.0.zip`，安装并启用。
2. 打开 KiraAI 左侧 **手机连接** 页面，填公网 IP、允许使用的聊天，点“保存并启动连接”。
3. 插件自动启动手机连接服务，生成并显示地址、连接密码和校验码。
4. 单独下载发行目录中的 APK，装到手机后复制这三项信息，开启无障碍并连接。

完整步骤在 ZIP 内的《新手使用说明.md》，源码根目录也有同一份。

无需下载源码、运行脚本或安装 Nginx。服务器安全组仍需放行手机连接端口（默认 TCP 8443）；Docker 安装还要映射同一端口。

## 配置页的其他项目

新用户优先使用“手机连接”页面。普通配置页里的服务器 IP、端口和允许的聊天与它使用同一份设置。

**插件里的 IP 和手机里的地址怎么填？** 插件填运行 KiraAI 的服务器公网 IP（云服务器控制台可查看），不是手机 IP。插件用它准备连接地址和让手机识别服务器的安全凭证。端口单独填，默认 8443；手机再填同一个 `公网IP:端口`，或直接复制插件生成的地址。连接始终由手机发起。

- 连接方式保持 `app`，内置手机连接服务保持开启。
- 自定义连接密码可以留空，插件会生成并保存密码；在手机连接页复制即可。
- 只允许这台手机、允许使用的人都是可选项。群聊时可限制为自己的用户 ID。
- 截图大小和等待时间先保持默认。使用 App 时，“仅 ADB”的项目不用改。

“允许使用的聊天”为空时，所有聊天都不能操作手机。连接密码和校验码只会显示在已登录的 KiraAI 管理页面里，不通过 AI 工具返回。

## 使用和更新

先试：“检查手机连接，然后打开设置。”普通聊天操作期间，AI 可按需发文字进度或截图。需要语音对话时，在 App 的通话页单独开始。

Android 8–10 只提供页面文字和按钮位置；Android 11 及以上支持按需截图。AI 看图片需要支持图片的模型，并正确配置 KiraAI 的图片识别功能。

想更快地看屏幕：当前聊天使用支持图片和工具调用的多模态模型，图片识别选 `native`。这样截图直接放进模型的下一轮请求；“图片描述”模式还需要另一个模型先解释图片，会多一次等待。

视频页面可试：“连续看几张当前画面，告诉我发生了什么。”`phone_watch` 一次取 2–4 张有先后顺序的图片，不录屏、不采集视频声音。需要 Android 11+ 和 `native`；受保护画面可能黑屏或失败，不能保证所有视频都能看见。

截图默认 JPEG，长边 1280；小字不清晰可改 PNG。新安装操作后等待默认 0.25 秒，旧设置不会被覆盖。图片结果包含截图传输耗时，实际速度仍取决于手机、网络和模型。

## AI 可调用的工具

| 工具 | 用途 |
| --- | --- |
| `phone_ui` | 只读页面控件，省去图片传输；看视频和图片仍需截图。 |
| `phone_apps` | 搜索可启动应用名称和包名，再按包名直接打开。 |
| `phone_status` | 检查连接，不返回密码。 |
| `phone_screenshot` | 看当前画面；可同时把截图发到聊天。 |
| `phone_tap` | 按最新画面点击，坐标范围 0–1000。 |
| `phone_swipe` | 上、下、左、右滑动。方向指手指移动方向。 |
| `phone_navigate` | 返回、回桌面、打开多任务。 |
| `phone_action` | 精确滑动、长按、输入、打开应用、等待等。 |
| `phone_watch` | 取得少量连续画面，供多模态模型理解变化。 |
| `phone_report` | 按需发送文字进度或已取得的截图。 |

工具返回的文字和图片会进入 KiraAI 上下文。模型是否调用工具由任务与模型能力决定；插件不会在没有会话触发时自行启动一个后台 AI。连续任务还需要足够的 Agent 迭代次数。

更新插件时若提示已存在，先卸载旧插件，保留“插件配置”和“插件数据”，再上传新版 ZIP。手机如提示版本过低或签名不一致，先保存连接信息，再卸载旧 App、安装并重新填写；卸载会清除手机设置。已经使用 Nginx 的用户可关闭“内置手机连接服务”继续使用；切换内置服务时选一个空闲端口，复制新连接信息。

可选 ADB 用法见 [ADB.md](ADB.md)。

## App 内通话

在手机连接页开启 App 内通话，并在 KiraAI 设置默认语音识别、聊天和语音合成模型。手机的通话页授权麦克风后再点开始；只聊天无需设备控制连接，使用手机工具时仍需无障碍及当前手机的控制连接。上下文保存在独立的 `phone:dm:<设备ID>` 会话。当前为轮流说话，支持手动打断，不自动重拨。旧 Nginx 代理需转发 `/ws/plugin/phone_control/voice`。

## 观察方式

操作后默认沿用最新有效观察方式；UI 操作继续返回控件，自动模式遇到空控件会尝试截图。需要看图时指定 observe_mode=screenshot。应用列表最多缓存 15 秒，刚安装或卸载应用可用 phone_apps(refresh=true) 刷新。截图缓存最多 16 条且图片合计不超过 32 MiB；清除较旧缓存后，发送旧图可能需要重新截图。
