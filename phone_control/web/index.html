连接入口

让手机找到你的服务器

填运行 KiraAI 的服务器 IP，不是手机或 Docker 的内部 IP。
推荐保持 5267。
为什么服务器和手机都要填地址？

插件用公网 IP 准备手机连接地址和安全凭证。这里填 IP，不加端口、http:// 或路径；手机里填生成的 IP 加端口，例如 203.0.113.10:5267。此 IP 仅作示例，请换成自己的。

管理网页用 HTTPS，手机使用同一个公网端口。
端口映射与高级设置

共用入口需要 Docker 映射“公网 5267 → 容器 8443”，管理网页使用 https://公网IP:5267。停止手机服务后，管理网页仍可使用。

通常保持 8443，不能与 Kira 在容器内的管理端口相同。建立共用入口后，更换 IP、内部端口或退出共用模式需要重启 Kira。

允许谁使用

只有你选定的聊天可以操作手机

在 KiraAI 的“会话管理”里复制会话 ID。留空时，所有聊天都不能操作手机。 8–128 位英文、数字或符号，不含空格。首次留空会生成 12 位密码；修改后手机也要改，原连接会断开。

语音陪伴

在手机里直接和 Kira 聊天

需先配置聊天、语音识别和语音合成模型。通话使用独立聊天记录。
首次只保存不会监听端口。启动后，重启 KiraAI 会自动恢复；停止后保持停止。运行中保存设置会重连。
共用入口只需放行 TCP 5267，Docker 映射为 5267 → 8443。
02

把三项内容复制到手机

在 App 的“连接设置”里粘贴，整行复制即可。

填写并保存设置后，点“保存并启动”，连接信息会显示在这里。

已包含公网 IP 和端口，不用自己拼接长后缀。
用于让手机确认连的是你的服务器，请完整复制。
03

安装 App，开始连接

准备好手机后，就可以回到聊天里试试。

下载手机 APK
1

安装手机 App

把项目发布的 APK 安装到手机，打开「KiraAI 手机助手」。

2

粘贴三项连接信息

在 App“连接设置”里填写地址、密码和校验码，再保存。

3

允许操作，再连接

开启本 App 的“无障碍服务”，返回 App 点“开始连接”。

4

和 Kira 说一句

在允许的聊天里说：“检查手机连接，然后打开设置。”

Android 8–10 提供控制、页面文字和按钮位置；Android 11 及以上还可以截图，不持续录屏。控制期间，可随时在 App 或通知里停止连接。

以后更新手机 App：侧边菜单 → 关于 → 应用更新。菜单出现红点时可查看新版。插件更新仍在 KiraAI 管理页面上传新版 ZIP。
