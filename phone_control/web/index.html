1. 在服务器这边准备连接

你现在填写的是安装 KiraAI 的那台服务器的信息。保存后，把下面生成的地址、密码和校验码复制到手机；手机再主动连接这台服务器。

在云服务器控制台查看。不是手机的 IP，也不是 Docker 容器的内部 IP。这里只填 IP，不加端口、http:// 或路径。
通常保持 8443。这是插件接收手机连接的端口，不是 KiraAI 管理网页端口。

为什么插件里也要填 IP？
插件用它准备手机连接地址，以及让手机认出这台服务器的安全凭证。手机里填写同一个 IP 加端口。例如这里填 203.0.113.10、端口 8443，手机就填 203.0.113.10:8443。此 IP 仅作示例，请换成自己的。

在 KiraAI 的“会话管理”里点“复制会话 ID”，粘贴到这里。一行一个；留空时所有聊天都不能操作手机。 8–128 位英文字母、数字或符号，不含空格。推荐用好记的短语加数字。首次留空会自动生成 12 位；修改后手机也要改，原连接会断开。 先在 KiraAI 配置默认聊天、语音识别和语音合成模型。手机通话使用独立聊天记录；控制手机仍需开启无障碍并连接。
首次保存不会监听端口。点击“保存并启动”后，KiraAI 重启会自动恢复；点击“停止服务”后保持停止。运行中保存设置会重连。
请在服务器安全组放行 TCP 8443。Docker 安装还需映射同一个端口。插件会自动准备其他连接信息。

2. 把三项内容复制到手机

填写并保存设置后，点“保存并启动”，连接信息会显示在这里。

已包含上面的公网 IP 和端口，整行复制到手机即可，不用自己拼接。

3. 安装 App，开始连接

下载手机 APK
  1. 把 APK 安装到手机，打开「KiraAI 手机助手」。
  2. 在“连接设置”里填入上面的地址、密码、校验码，再保存。
  3. 开启本 App 的“无障碍服务”，返回 App 点“开始连接”。
  4. 手机连上后，在刚才允许的聊天里说：“检查手机连接，然后打开设置。”

Android 8–10 提供控制、页面文字和按钮位置；Android 11 及以上还可以截图。不会持续录屏。停止时点击 App 或通知里的“停止连接”。
