# 插件管理页专属角色素材

本目录为插件单独生成的一套素材，与 App 使用同一个参考角色、蓝色与淡紫色画风，表情、动作和场景另行绘制。没有修改 App 的图片。

使用内置 image_gen 生成，完整提示词、原始生成文件及参考图角色记录在 `prompts.json`。图片保留生成后的原始字节；表情包保留真实透明通道。

| 文件 | 用途与动作 |
| --- | --- |
| scene-settings.png | 服务器设置：电脑旁操作键盘，指向服务器，认真微笑 |
| scene-pairing.png | 手机配对：展示手机，摊手邀请，温和笑容 |
| scene-guide.png | 安装说明：翻开说明册，举指讲解，鼓励地眨眼 |
| settings.png | 设置页签：齿轮和扳手，专注调整 |
| link.png | 配对页签、连接入口及等待连接：手机和无线信号，期待连接 |
| guide.png | 说明页签：拿书举指，讲解下一步 |
| call.png | App 内通话：耳机与麦克风，开口打招呼 |
| shield.png | 聊天授权：双手持盾，守住允许范围 |
| connected.png | 手机已连接：手机勾号与拇指，开心确认 |
| rest.png | 服务未启动：捧杯安静等待 |
| error.png | 启动或连接出错：检查断开的接头，疑惑思考 |

人物场景按 2:3 比例完整显示，使用 contain；电脑上有独立右栏，窄屏上位于标题旁，表单另起一行。文字、卡片、按钮和状态表情都不覆盖人物正脸或双手；说明文字放在图片外。

状态表情只读服务器已确认的快照，不会启动功能，也不把正在连接视为成功。状态在初次加载、刷新和保存/启停后更新。页签保留原来的伸展与回弹效果；不让整张场景图持续动画。

图片、脚本和样式随插件 ZIP 本地分发，受 Kira 管理员页面登录保护，不依赖外部图片网站。后续替换素材时同步检查打包清单、安装路由及 50 MiB 的压缩/解压总量限制。

## 插件和 APK 头像

另行生成的 `plugin-avatar.png` 用于本页左上角。插件清单通过 `icon.png` 显示同款头像：仓库根目录与 `phone_control/` 各有一份相同字节的 `icon.png`，分别供 GitHub 根安装和插件 ZIP 安装解析，两个清单继续使用相同的相对路径。替换头像时同步这三份文件。

APK 使用另一张拿手机的头像，原图在 `android-app/app/src/main/res/drawable-nodpi/kira_launcher_art.png`。原生图标 XML 加入安全内边距并配浅蓝底，由 Android 桌面裁成圆形或圆角。原始生成提示词、文件名和用途记录在 `avatar-prompts.json`；没有覆盖原来的页面背景和功能表情。
